I. THAY ĐỔI SERVER (Backend)
================================================================================

1. CẤU HÌNH MONGODB
   - File: server_app/.env
   - Thay đổi:
     + Thêm tên database "test" vào MongoDB URI
     + URL cũ: mongodb+srv://...mongodb.net/?retryWrites...
     + URL mới: mongodb+srv://...mongodb.net/test?retryWrites...

2. MODEL PRODUCT
   - File: server_app/Models/product.js
   - Thay đổi:
     + Thêm trường "stock" (Number, default: 0) - Số lượng tồn kho
     + Xóa trường "count" (không dùng nữa)
     + Giữ nguyên trường "gender" (String) - Giới tính sản phẩm

3. FILE SEED DATA
   - File: server_app/seed.js
   - Thay đổi lớn:
     
     a) Import và xóa dữ liệu:
        + Chỉ import Product và Category
        + Xóa các model khác (Users, Payment, Delivery, Permission, Order, 
          Coupon, Sale, Note, Comment, Cart, Favorite, Detail_Order)
        + Giữ code đơn giản, chỉ seed Product và Category

     b) Category:
        + Giảm từ 6 xuống 2 categories:
          * "Áo"
          * "Quần"
        + Không còn phân loại theo giới tính trong category

     c) Products (18 sản phẩm):
        + THÊM thuộc tính đầy đủ theo schema:
          * id_category: ID của category (Áo hoặc Quần)
          * name_product: Tên sản phẩm
          * price_product: Giá (String)
          * image: URL ảnh Cloudinary
          * describe: Mô tả chi tiết
          * gender: 'male', 'female', hoặc 'unisex'
          * stock: Số lượng tồn kho

        + Phân bổ sản phẩm:
          * 6 sản phẩm Nam (male): 3 áo + 3 quần
          * 6 sản phẩm Nữ (female): 3 áo + 3 quần
          * 6 sản phẩm Unisex: 3 áo + 3 quần
          * 6 sản phẩm hết hàng (stock = 0)

     d) URL ảnh:
        + Thay đổi từ localhost sang Cloudinary
        + Format: https://res.cloudinary.com/dofpzisn0/image/upload/v1732600000/products/[ten-san-pham].jpg
        + Cloud name: dofpzisn0 (từ file .env)

4. API ENDPOINTS (Không thay đổi)
   - GET /api/Product - Lấy tất cả sản phẩm
   - GET /api/Product/category?id_category=xxx - Lọc theo category
   - GET /api/Product/:id - Chi tiết sản phẩm
   - GET /api/Product/gender/:gender - Lọc theo giới tính (male/female/unisex)
   - GET /api/Product/category/pagination - Phân trang
   - GET /api/Product/scoll/page - Search scroll
