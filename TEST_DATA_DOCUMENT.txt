1.1. Mục đích
    Tài liệu này cung cấp dữ liệu mẫu để sử dụng trong quá trình kiểm thử
    các module của hệ thống E-commerce.

1.2. Phạm vi
    - User accounts (khách hàng và admin)
    - Product catalog
    - Shopping cart items
    - Orders & Payments
    - Coupons & Sales
    - Reviews & Comments

1.3. Cách sử dụng
    - Sử dụng seed.js để import dữ liệu vào MongoDB
    - Có thể tạo thêm data qua Admin Panel hoặc API
    - Reset data trước mỗi round test
