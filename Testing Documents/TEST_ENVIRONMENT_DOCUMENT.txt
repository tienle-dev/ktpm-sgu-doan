        build: ./server_app
        ports:
          - "8000:8000"
        environment:
          - NODE_ENV=test
          - MONGODB_URI=mongodb://mongodb:27017/ecommerce_test
        depends_on:
          - mongodb

                        15. TROUBLESHOOTING
================================================================================

15.1. Common Issues & Solutions
---------------------------------

    Issue: "npm not recognized"
    Solution: Set PowerShell execution policy
              Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

    Issue: "Error: digital envelope routines::unsupported"
    Solution: Add NODE_OPTIONS=--openssl-legacy-provider to .env

    Issue: "Port 3000 already in use"
    Solution: Kill process or change PORT in .env

    Issue: "MongoDB connection failed"
    Solution: Check MongoDB is running: mongod --version
              Check connection string in .env

    Issue: "CORS error in browser"
    Solution: Check server CORS configuration allows localhost:3000

15.2. Health Check Commands
-----------------------------
    Check Node.js:      node --version (should be 16.x - 18.x)
    Check npm:          npm --version
    Check MongoDB:      mongod --version OR check Atlas connection
    Check server:       curl http://localhost:8000/api/User
    Check client:       curl http://localhost:3000

15.3. Log Locations
--------------------
    Server Logs:        server_app/logs/app.log
    Client Logs:        Browser DevTools Console
    Database Logs:      MongoDB Compass / Atlas Logs
    Test Results:       /coverage/lcov-report/index.html

                        16. INSTALLATION GUIDE
================================================================================

16.1. Fresh Environment Setup (Step-by-step)
----------------------------------------------

    Step 1: Install Prerequisites
    ------------------------------
    1.1. Install Node.js 16.x or 18.x LTS
         Download: https://nodejs.org/
    
    1.2. Install Git
         Download: https://git-scm.com/
    
    1.3. Install MongoDB (local) OR setup MongoDB Atlas (cloud)
         Local: https://www.mongodb.com/try/download/community
         Atlas: https://www.mongodb.com/cloud/atlas

    Step 2: Clone Repository
    -------------------------
    git clone https://github.com/tienle-dev/ktpm-sgu-doan.git
    cd ktpm-sgu-doan

    Step 3: Install Dependencies
    -----------------------------
    npm run install-all
    (This installs dependencies for server, client, and admin)

    Step 4: Configure Environment Variables
    -----------------------------------------
    4.1. Copy .env.example to .env in each app:
         cp server_app/.env.example server_app/.env
         cp client_app/.env.example client_app/.env
         cp admin_app/.env.example admin_app/.env
    
    4.2. Update values in each .env file

    Step 5: Seed Test Database
    ---------------------------
    cd server_app
    npm run seed

    Step 6: Start All Applications
    -------------------------------
    cd ..
    npm run dev
    (Starts server on :8000, client on :3000, admin on :3001)

    Step 7: Verify Installation
    ----------------------------
    - Open http://localhost:3000 (Client app)
    - Open http://localhost:3001 (Admin app)
    - Check server logs for successful connection

16.2. Quick Start (For Experienced Developers)
------------------------------------------------
    git clone https://github.com/tienle-dev/ktpm-sgu-doan.git
    cd ktpm-sgu-doan
    npm run install-all
    # Configure .env files
    cd server_app && npm run seed && cd ..
    npm run dev
