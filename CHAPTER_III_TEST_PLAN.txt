3.1 GIỚI THIỆU
═══════════════════════════════════════════════════════════════════════════════

3.1.1 Mục đích tài liệu

Mục đích của tài liệu Kế hoạch Kiểm thử (Test Plan) là xác định một cách chính thức 
các mục tiêu, phạm vi, chiến lược, nguồn lực và lịch trình cho các hoạt động kiểm 
thử phần mềm của dự án Website Bán Hàng Thời Trang (KTPM-SGU-DOAN).

Tài liệu này đóng vai trò là kim chỉ nam cho toàn bộ quá trình kiểm thử, nhằm đảm bảo:
• Chất lượng (Quality): Hệ thống hoạt động đúng theo yêu cầu
• Độ ổn định (Stability): Không có lỗi nghiêm trọng ảnh hưởng tính năng chính
• Bảo mật (Security): Ngăn chặn các lỗ hổng như XSS, SQL Injection
• Hiệu suất (Performance): Thời gian phản hồi nhanh, tải trang dưới 3 giây

3.1.2 Phạm vi áp dụng

Tài liệu này áp dụng cho dự án KTPM-SGU-DOAN, đặc biệt tập trung vào các giai đoạn:
• Kiểm thử Đơn vị (Unit Testing) - Frontend & Backend
• Kiểm thử Tích hợp (Integration Testing) - Frontend-Backend-Database
• Kiểm thử Hệ thống (System Testing) - Toàn bộ workflow
• Kiểm thử Chấp nhận Người dùng (User Acceptance Testing - UAT)

Bao gồm:
• Phần mềm: Giao diện người dùng (Frontend - React.js) và dịch vụ logic nghiệp vụ (Backend - Node.js/Express)
• Cơ sở dữ liệu: MongoDB
• Tích hợp: API MoMo (thanh toán), Email Service (xác nhận đơn hàng)
• Đối tượng: Nhóm Kiểm thử, Nhóm Phát triển, và Giảng viên hướng dẫn/Quản lý dự án

3.1.3 Tài liệu Tham khảo và Phiên bản

Việc xây dựng Test Plan dựa trên các tài liệu:
• Tài liệu Đặc tả Yêu cầu (Requirements Specification)
• Tài liệu Test Cases - 86 test cases đã được định nghĩa
• Mô tả Use-case hệ thống
• Các lược đồ thiết kế hệ thống (ERD, UI Flow)
• Tài liệu API Backend
• MongoDB Data Model

Phiên bản hiện tại: 1.0 (Ngày 16/12/2025)


3.2 BỐI CẢNH
═══════════════════════════════════════════════════════════════════════════════

    KTPM-SGU-DOAN (E-commerce Fashion Website) là một hệ thống thương mại điện tử cho 
    phép người dùng duyệt, tìm kiếm, mua sắm sản phẩm thời trang trực tuyến.

Kiến trúc hệ thống:
┌─────────────────────────────────────────────────────────┐
│                  Frontend (React.js)                    │
│  ├─ Client App (Khách hàng - Buyer)                    │
│  │  ├─ Sign In/Sign Up                                 │
│  │  ├─ Product Catalog (Search, Filter, Sort)          │
│  │  ├─ Shopping Cart                                   │
│  │  ├─ Checkout & Payment (MoMo, COD)                 │
│  │  └─ Review & Rating System                          │
│  └─ Admin App (Quản trị viên)                          │
│     ├─ User Management                                 │
│     ├─ Product Management                              │
│     └─ Order Management                                │
├─────────────────────────────────────────────────────────┤
│              Backend (Node.js/Express)                 │
│  ├─ API Routes (User, Product, Cart, Order, Review)   │
│  ├─ Controllers (Business Logic)                       │
│  ├─ Models (Data Validation)                           │
│  └─ Services (Payment, Email)                          │
├─────────────────────────────────────────────────────────┤
│           Database (MongoDB & External Services)        │
│  ├─ MongoDB Collections                                │
│  ├─ MoMo API (Payment Gateway)                        │
│  └─ Nodemailer (Email Service)                         │
└─────────────────────────────────────────────────────────┘

Hai vai trò người dùng chính:
1. Buyer (Khách hàng):
   - Đăng ký tài khoản, đăng nhập
   - Duyệt, tìm kiếm, lọc sản phẩm
   - Thêm vào giỏ hàng
   - Thanh toán qua MoMo hoặc COD
   - Đánh giá sản phẩm

2. Administrator (Quản trị viên):
   - Quản lý người dùng (kích hoạt, khóa tài khoản)
   - Quản lý sản phẩm (thêm, sửa, xóa)
   - Quản lý danh mục
   - Quản lý đơn hàng
   - Quản lý khuyến mãi, mã giảm giá

3.7 KHẢI NĂNG SỬ DỤNG (USABILITY)
═══════════════════════════════════════════════════════════════════════════════

Mục tiêu là đảm bảo rằng ứng dụng web dễ sử dụng, trực quan và thân thiện với người dùng.

3.7.1 Dễ sử dụng (Ease of Use)

• Người dùng có thể dễ dàng:
  - Đăng nhập / đăng ký tài khoản
  - Tìm kiếm sản phẩm (search bar)
  - Lọc sản phẩm (category, price, availability)
  - Xem chi tiết sản phẩm
  - Thêm vào giỏ hàng
  - Thanh toán

• Quy trình mua hàng phải:
  - Rõ ràng, không nhập nhèm
  - Ngắn gọn (tối thiểu 5 bước)
  - Có hướng dẫn / hint khi cần
  - Không bắt buộc điền quá nhiều thông tin

3.7.2 Giao diện người dùng (UI)

• Giao diện phải:
  - Hiện đại, đẹp mắt
  - Bố cục logic, dễ scan
  - Màu sắc nhất quán (theme)
  - Phông chữ dễ đọc

• Các thành phần quan trọng phải:
  - Nổi bật, dễ thấy
  - Có tooltip/help text khi hover
  - Responsive trên mobile, tablet, desktop

• Thông báo lỗi phải:
  - Cụ thể, không chung chung ("Invalid input")
  - Hữu ích ("Email already exists" hoặc "Password must be at least 8 chars")
  - Hiển thị ở vị trí rõ ràng (không cuộn trang)


3.8 RÀNG BUỘC THIẾT KẾ (DESIGN CONSTRAINTS)
═══════════════════════════════════════════════════════════════════════════════

3.8.1 Tương thích trình duyệt

Ứng dụng phải hoạt động chính xác trên các trình duyệt mới nhất:
• Google Chrome 120+
• Mozilla Firefox 121+
• Safari 17+
• Microsoft Edge 120+

3.8.2 Hệ thống

• Frontend: Chạy trên trình duyệt web tiêu chuẩn (không cần extension)
• Backend: Yêu cầu môi trường Node.js 16.20.0+
• Cơ sở dữ liệu: MongoDB (local hoặc cloud)
• APIs: RESTful, JSON response format

3.8.3 Hiệu năng / Độ phản hồi

• Thời gian tải trang chủ: < 3 giây
• Thời gian tải danh sách sản phẩm: < 3 giây
• Thời gian phản hồi khi tìm kiếm/lọc: < 2 giây
• Thời gian thêm vào giỏ hàng: < 1 giây (real-time)
• Thời gian gửi review: < 2 giây
• API response time: < 500ms
• Database query: < 100ms

3.8.4 Dung lượng & Lưu trữ

• Dung lượng trang (JS + CSS + HTML): < 5MB
• Ảnh sản phẩm: Optimize, < 500KB per image
• Cache: Sử dụng browser cache cho static files


3.9 GIAO DIỆN HỆ THỐNG (INTERFACES)
═══════════════════════════════════════════════════════════════════════════════

3.9.1 Giao diện người dùng (User Interfaces)

Hệ thống cung cấp ba giao diện chính:

1. Customer UI (Client App):
   • Trang chủ (Home)
   • Danh sách sản phẩm (Product List) - Với Search, Filter, Sort
   • Chi tiết sản phẩm (Product Detail) - Với reviews & rating
   • Giỏ hàng (Shopping Cart)
   • Thanh toán (Checkout) - Với MoMo & COD options
   • Xác nhận đơn hàng (Order Confirmation)
   • Lịch sử mua hàng (Order History)
   • Hồ sơ người dùng (User Profile)

2. Admin UI (Admin App):
   • Dashboard - Tổng quan thống kê
   • Quản lý sản phẩm (Product Management)
   • Quản lý danh mục (Category Management)
   • Quản lý người dùng (User Management)
   • Quản lý đơn hàng (Order Management)
   • Quản lý mã giảm giá (Coupon Management)

3. Mobile UI (Responsive):
   • Tất cả giao diện phía khách hàng phải responsive
   • Menu ẩn/hiện trên mobile
   • Touch-friendly buttons & inputs

3.9.2 Giao diện hệ thống (System Interfaces)

API Communication:
• Frontend (React) ↔ Backend (Express) qua RESTful endpoints
• Communication: HTTP/HTTPS
• Format: JSON
• Authentication: JWT tokens

Dịch vụ bên ngoài được tích hợp:
1. MoMo API (Payment Gateway):
   - Xử lý thanh toán online
   - Callback xác nhận thanh toán

2. Nodemailer (Email Service):
   - Gửi email xác nhận đơn hàng
   - Gửi email reset password
   - Gửi email thông báo review được phê duyệt

3. Database (MongoDB):
   - Lưu trữ users, products, orders, reviews, etc.
