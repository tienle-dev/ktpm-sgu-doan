V. BOTTLENECK ANALYSIS
================================================================================

1. Database Queries (HIGH IMPACT)
   - Search endpoint: Full text search chưa được index
   - Order creation: Multiple queries không batch
   - Recommendation: Add indexes, optimize queries

2. Memory Usage
   - 100 users: ~250MB
   - 500 users: ~680MB
   - 1000 users: ~1.2GB (approaching limit)

3. CPU Usage
   - 100 users: ~25%
   - 500 users: ~65%
   - 1000 users: ~95% (bottleneck)

================================================================================
VI. RECOMMENDATIONS
================================================================================

1. [HIGH] Database Optimization
   - Add compound index cho search: { name: 'text', category: 1, price: 1 }
   - Add index cho orders: { userId: 1, createdAt: -1 }
   - Enable MongoDB query caching

2. [HIGH] Implement Caching
   - Redis cache cho product listing (TTL: 5 minutes)
   - Cache categories (TTL: 1 hour)
   - Session store với Redis

3. [MEDIUM] Code Optimization
   - Use pagination với limit
   - Implement lazy loading cho images
   - Compress API responses (gzip)

4. [MEDIUM] Infrastructure
   - Upgrade to larger server instance
   - Consider horizontal scaling với load balancer
   - Use CDN cho static assets

5. [LOW] Monitoring
   - Implement APM (Application Performance Monitoring)
   - Set up alerts cho high response times
   - Log slow queries
