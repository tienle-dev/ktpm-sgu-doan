IV. HƯỚNG DẪN CHẠY TEST
================================================================================

1. Chạy Unit Tests (Jest):
   # Coupon tests
   cd server_app && npm test -- tests/unit/coupon.test.js
   
   # Search/Filter tests
   cd server_app && npm test -- tests/unit/search-filter.test.js
   
   # Admin Panel tests
   cd admin_app && npm test -- src/tests/AdminPanel.test.js

2. Chạy E2E Tests (Cypress):
   # Interactive mode
   cd admin_app && npx cypress open
   
   # Headless mode
   cd admin_app && npx cypress run --spec "cypress/e2e/admin-crud.cy.js"

3. Xem Reports:
   - Security: test-reports/security-report.txt
   - Performance: test-reports/performance-test-results.txt
